# LogBill – Work Logs → Clean Invoices

**Fastest path to first revenue for freelancers & small agencies.**

## What it does (MVP)

1. Add clients (name, email, default hourly rate, currency)
2. Log work (date, description, hours or fixed amount)
3. Select unbilled logs → Generate professional invoice
4. Mark as Paid
5. See outstanding amount on dashboard

Data is stored in the browser (localStorage). No account, no backend required for the first version. Perfect for demos and early sales.

## How to deploy in 3 minutes (free)

### Option A – Netlify Drop (fastest)
1. Go to https://app.netlify.com/drop
2. Drag the `index.html` file
3. Get a live URL instantly

### Option B – Cloudflare Pages
1. Create a new project
2. Upload the folder or connect a Git repo containing only `index.html`
3. Deploy

### Option C – GitHub Pages
1. Create a public repo
2. Upload `index.html`
3. Enable Pages on the main branch
